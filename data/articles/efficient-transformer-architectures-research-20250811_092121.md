## Web Search Summary on Efficient Transformer Architectures

- Efficient Transformer architectures are a category of Transformer models designed to reduce the computational and memory costs associated with the original Transformer's self-attention mechanism.
- A key survey paper on this topic is 'Efficient Transformers: A Survey' by Tay et al. (2020), which provides a comprehensive overview of various 'X-former' models.
- These architectures often achieve efficiency through modifications to the attention mechanism, such as sparse attention, linear attention, or low-rank approximations, as well as other architectural changes and optimization techniques.
- Examples of efficient Transformer models mentioned include Reformer, Linformer, Performer, and Longformer, which aim to improve speed and efficiency for practical applications.

## Web Search Summary on standard transformer self-attention quadratic complexity explanation

- Standard transformer self-attention suffers from quadratic complexity, denoted as O(N^2), where N is the sequence length.
- The quadratic complexity primarily arises from the matrix multiplication of the Query (Q) matrix (N x D) with the transpose of the Key (K) matrix (D x N), which results in an N x N attention score matrix.
- Computing the N x N attention score matrix from Q and K^T requires approximately N * D * N (or N^2 * D) floating-point operations, making the dominant factor N^2.
- This quadratic scaling with sequence length is a significant computational bottleneck for processing very long sequences, leading to active research in 'Efficient Transformers' and methods like sparse attention to reduce this cost.

## Web Search Summary on transformer self-attention memory complexity N^2 explanation

- The self-attention mechanism in transformers has a time- and space-complexity that is quadratic in the length of the input (N).
- The quadratic memory complexity (O(N^2)) arises from the need to store the attention scores matrix, which is computed by multiplying the Query (Q) and Key (K^T) matrices.
- If the input sequence length is N, and Q and K are (N, d) matrices, their product (Q * K^T) results in an (N, N) attention scores matrix, requiring O(N^2) memory.
